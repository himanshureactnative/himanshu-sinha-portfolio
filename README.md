# Himanshu Sinha Portfolio

A dependency-light Vite portfolio. The UI is built with plain HTML/CSS/JS so there is no React/lucide runtime dependency and the page renders immediately.

## Run

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.
